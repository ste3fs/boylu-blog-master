# 博客项目 PR 自动验收提示词模板

将下面整段直接发给 Codex，替换花括号变量即可：

```text
你现在是我的 PR 验收工程师。请对 PR #{PR_NUMBER} 做自动验收，项目根目录是 <PROJECT_ROOT>。

验收目标：
1. 先用 GitHub MCP 读取该 PR 的改动、评论、CI 状态，输出风险点。
2. 再用 Playwright 回归以下页面：
   - 前台登录页：/login
   - 文章页：从首页进入首篇文章详情（/post/:id）
   - 相册页：/photos
   - 后台管理页：/dashboard、/site/album
3. 对每个页面给出：是否通过、失败步骤、可能原因、修复建议。
4. 输出最终结论：可合并 / 不可合并，并给出阻塞项清单。

执行约束：
- 不要只讲思路，直接执行检查。
- 优先给结论，再给证据。
- 发现问题时，必须给到文件路径和最小修复方案。
- 如果后台鉴权缺少 ADMIN_TOKEN，明确标记为“环境阻塞”而非功能失败。

输出格式：
【PR概况】
- 标题：
- 变更范围：
- CI 状态：

【风险清单】
1. [级别] 问题描述
2. ...

【回归结果】
- 登录页：通过/失败（证据）
- 文章页：通过/失败（证据）
- 相册页：通过/失败（证据）
- 管理页：通过/失败/环境阻塞（证据）

【结论】
- 是否可合并：
- 阻塞项：
- 建议下一步：
```
